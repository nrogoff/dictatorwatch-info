# DictatorWatch.info SQL Server database project

This module contains the SQL Server database schema and seed deployment scripts for DictatorWatch.info.

## Contents

- `dictatorwatch.info.db.sln` - Solution file for the database project.
- `dictatorwatch.info.db.sqlproj` - SSDT SQL project.
- `dbo/Tables` - Core relational schema definitions.
- `Data/Seeding` - Post-deployment and seed data scripts.
